You are forbidden to change comments like following:

```javascript
/*
 * Brief description of the file
 * IMPORTS:
 *  - imported libraries
 *  - from internal directories
 *      - imported objects: purpose
 * EXPORTS:
 *  - exported objects
 */
```

```javascript
/*
 * END OF 'filename' FILE
 */
```

```javascript
/*
 * Brief description of the structure
 * Fields:
 *  - field name - purpose
 */
```

```javascript
/*
 * Brief description of the function
 * Route: API path
 * Request body:
 *  - field: description
 *  - (if a nested structure is passed)
 *  - field: structure with following fields:
 *      - subfield: description
 * Response body:
 *  - field - description
 */
```

```javascript
/*
 * Brief description of the function
 * PARAMETERS:
 *  - field: description
 *  - (if a nested structure is passed)
 *  - field: structure with following fields:
 *      - subfield: description
 * RETURNS:
 *  - field - description
 */
```

```javascript
/*
 * End of 'function' function
 */
```

In case you are asked to change these comments, write or rewrite new comments under ones which are forbidden to change.
